## Run locally

Clone the repository and start a local web server from its folder:

```bash
git clone https://github.com/bhargava8484-eng/Portoflio.git
cd Portoflio
python3 -m http.server 8000
```

Then visit http://localhost:8000. Serving it over HTTP is recommended so the contact form can submit correctly.

## Deployment

The repository includes a GitHub Actions workflow that deploys the site to GitHub Pages when changes are pushed to the `main` branch.
